# Obstacle-Avoiding-Autonomous-Car
Arduino-based Autonomous Obstacle Avoiding Robot using Ultrasonic Sensor, Servo Motor and Motor Shield.

## Components
1) Arduino Uno
2) Motor Shield L293D
3) TT Gear Motor
4) Rubber Wheels
5) Servo Motor
6) Ultrasonic Sensor
7) 18650 Li-ion Battery
8) Battery Holder
9) Male and Female Jumper
10) DC Power Switch
11) Acrylic Sheet

## Features
- Obstacle Detection
- Autonomous Navigation
- Automatic Path Selection
